# Импорт раздела из .zip

На iPhone: открой нужную тему или раздел, нажми **＋**, затем **Импорт из Файлов**, выбери `.zip`.
Архив распакуется внутрь текущей папки как новый раздел. Если папка с таким именем уже есть,
к имени добавится « 2», « 3» и т.д. Существующие записи никогда не перезаписываются.

## Как устроен архив

Архив — это просто папка с `.md` файлами. Вложенные папки становятся подразделами, `.md` файлы — записями.

```
Кости.zip
└── Кости/                       ← раздел (одна папка верхнего уровня)
    ├── Функции костей.md        ← запись «Функции костей»
    ├── Строение кости.md
    ├── images/                  ← картинки (папка не показывается как раздел)
    │   ├── skeleton.png
    │   └── срез.jpg
    └── Соединения костей/       ← подраздел, вложенность любая
        ├── Суставы.md
        └── images/
            └── сустав.png
```

### Как называется раздел

- **В архиве одна папка верхнего уровня** (как выше). Раздел получает имя этой папки. Именно так
  получается, если на Mac нажать на папку правой кнопкой и выбрать **Сжать «Кости»**.
- **Файлы лежат прямо в корне архива.** Раздел называется по имени архива: `Кости.zip` → «Кости».

```
Кости.zip
├── Функции костей.md
├── Строение кости.md
└── images/skeleton.png
```

Чтобы импортировать целую **тему** с разделами, сделай тему верхней папкой:
`Биология/Кости/…`, `Биология/Ткани/…` и сожми папку «Биология».

## Правила для файлов

| Что | Правило |
| --- | --- |
| Запись | файл `.md` (или `.markdown`), кодировка UTF-8. Имя файла без `.md` — название записи |
| Раздел | любая папка |
| Картинки | `.png`, `.jpg`, `.jpeg`, `.heic`, `.gif`. Лучше класть в папку `images/` рядом с записью |
| Скрытое | папки `images`, `img`, `assets`, `attachments`, `media` и всё, что начинается с `_` или `.`, в списке не показывается |
| Мусор macOS | `__MACOSX/`, `.DS_Store`, `._*` пропускаются автоматически |
| Порядок | по алфавиту с учётом чисел: «2 Ткани» идёт раньше «10 Кости». Чтобы задать порядок, начни имя с номера |
| Имена | русские буквы и пробелы можно. Нельзя `/` и `:` |

Сжатие в архиве: обычное (Deflate) или без сжатия. Так сохраняют Finder, Windows, 7-Zip и `zip`.
Архивы больше 4 ГБ (ZIP64) не поддерживаются.

## Как писать запись

```markdown
# Функции костей

Кости выполняют **опорную** и ==защитную== функции.

1. Опора
2. Защита
   - черепная коробка → мозг
3. Кроветворение — *красный костный мозг*

![Скелет](images/skeleton.png)

| Функция | Пример |
| :-- | :--: |
| Опора | позвоночник |
| Защита | рёбра |

Прочность: $\sigma = \frac{F}{S}$

$$
m = \rho V
$$

> Цитата или важное замечание

- [x] выучил
- [ ] повторить
```

Что поддерживается:

- **Заголовки** `#`, `##`, `###`.
- **Начертание**: `**жирный**`, `*курсив*`, `==выделение==`, `` `код` ``.
- **Списки**: `-`, `1.` и чекбоксы `- [ ]` / `- [x]`. Вложенность задаётся отступом в 2–4 пробела.
- **Таблицы** через `|`. Выравнивание колонок `:--` (влево), `:--:` (по центру), `--:` (вправо).
  Перенос строки в ячейке — `<br>`.
- **Картинки**:
  - `![подпись](images/фото.jpg)` — путь от папки записи.
  - `![[фото.jpg]]` — как в Obsidian, файл ищется по имени по всей библиотеке.
  - Пробелы в пути можно писать как есть или как `%20`.
- **Формулы** LaTeX:
  - в строке: `$...$` или `\(...\)`;
  - отдельной строкой: `$$...$$`, `\[...\]` или блок ```` ```math ````.
    `$$...$$` можно писать и прямо в строке или пункте списка, формула встанет отдельной строкой, как в Obsidian;
  - химия: `\rightleftharpoons`, `\overset{\text{H}_2\text{O}}{\rightleftharpoons}`, `\xrightarrow[под]{над}`,
    `\underset`, `\stackrel`, `\implies`, `\iff`.
- **Блоки**: цитаты `>`, блоки кода ```` ``` ````, линия `---`.
- **Выноски Obsidian**: `> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!DANGER]`,
  `> [!EXAMPLE]`, `> [!QUESTION]`. После типа можно написать свой заголовок: `> [!TIP] Запомни`.
- **Шапка YAML** (`---` … `---` в начале файла) игнорируется.

## Как сделать архив на Mac

1. Создай папку раздела, положи туда `.md` файлы и папку `images`.
2. Правая кнопка по папке → **Сжать «…»**.
3. Перекинь `.zip` на iPhone (AirDrop → «Сохранить в Файлы», или через iCloud Drive).
4. В Шпоре: **＋** → **Импорт из Файлов** → выбери архив.

Можно и без архива. Если включён iCloud, просто положи папку в iCloud Drive → «Шпора» на Mac,
и она сама появится на телефоне и часах.
